# InterviewAI — Frontend

This folder is the **React + Vite** single-page app for InterviewAI (auth, interview flow, coding practice UI).

## Documentation (English)

All setup, environment variables, API overview, and run instructions are in the **repository root**:

**[../README.md](../README.md)**

## Quick commands

```bash
npm install
npm run dev      # development server
npm run build    # production build
npm run lint     # ESLint
```

Configure `VITE_SERVER_URL` and `VITE_FIREBASE_APIKEY` in `.env` (see root README).
